# 戦闘の設計メモ

`game/battle-rules.js`（純関数）と `game/main.js` の戦闘部分。触るときの注意点。

## ワザの使用回数は戦闘をまたいで残る

MP は無い。ワザごとに `uses`（`content.js` の `SKILLS`）があり、**減ったまま
次の戦闘に持ち越される**。戻せるのは3か所だけ。

| 戻る場所                 | 実装                                       |
| ------------------------ | ------------------------------------------ |
| 各章の祭壇（`4` タイル） | 無料・何度でも。HP と戦闘不能も一緒に治る  |
| 町の宿屋                 | 有料                                       |
| 章のはじまり             | `startChapter2/3/4/5`。HP 全回復と同じ場所 |

**「旅立ち」(`travelTo`) では戻らない。** HP も戻らないので揃えてある。

### 回数の目安

持ち越すので、1戦闘ぶんではなく**祭壇から祭壇までのひと区切りぶん**で考える。
役割で段を分けてある。

| 段                           | 回数 | 例                                           |
| ---------------------------- | ---- | -------------------------------------------- |
| 道中の主力（低倍率・単体）   | 6〜8 | 三日月返し8、氷月弾6、月雫の癒し6            |
| 中位（役割もち・全体・強化） | 3〜5 | 星火斬り5、鎧断ち4、兜割り4、月光の護り3     |
| 切り札・奥の手               | 2    | 暁天一閃2、牙断ち乱れ2、星降り2、暁光の癒し2 |

マップは1面 192 マス、遭遇率は4歩目以降 13.5% なので、1面あたり 3〜6 戦。
祭壇はほぼ全ての面にひとつあるが、**塔の2階だけは無い**（`TOWER_MAPS.2`）。
ここが一番きつくなる区間として意図的にそのままにしてある。

### なぜ持ち越すのか

以前は `startBattle()` が毎回 `skillUses` を満タンに戻していた。消耗がゼロだと
どの戦闘でも最上位のワザを撃つのが最適解になり、三日月返しのような序盤のワザに
使い道が無くなる。持ち越しにすると「道中は安いワザ、切り札はボスまで取っておく」
という判断が生まれ、残弾の多い序盤のワザが**持続可能な選択肢**という席に座る。

### 触るときの注意

- **`skillUses` はセーブに入っている。** 項目が無い古いセーブは
  `normalizeSkillUses()` が満タン扱いにする（回数ゼロで詰まないため）
- 満タンに戻すのは `restoreSkillUses()` 一本に寄せてある。増やすときはここを呼ぶ
- 残弾ゼロでも「たたかう」と「ためる」(1.5倍) が残るので、詰みはしない

## 多段斬りは防御を段ごとに引く

`power` は**合計の倍率**で、`hits` で割ったものが1段ぶんの攻撃力になる。
防御は1段ごとに引かれる。

```
1段ぶん = (atk + 2) * power / hits
1段のダメージ = max(2, 1段ぶん - floor(def / 2) + rand(-2,2))
```

つまり**多段は硬い相手ほど損をする**。柔らかい相手には刺さり、鎧のような相手には
`ignoreDef` の鎧断ちが答えになる、という住み分け。敵の連続攻撃（`hits` を持つ
`selectEnemyAction` の行動）はもともと1発ずつ `enemyHit()` を通るので、
同じ扱いになっている。

段ごとに引くぶん合計が下がるので、多段ワザの `power` はその分を見込んで
上げてある（三日月返し 1.3→1.4、牙断ち乱れ 1.95→2.1）。**`hits` を変えるときは
`power` も見直すこと。** 目安は `power' = power + (hits-1) * def / (2 * atk)`。

## 閃きは格上ほど起きやすい

`sparkChanceForAction(action, charged, threat)`。`threat` は `sparkThreat()` が
出す「相手の格」で、**その章の雑魚の平均経験値を 1.0 とした比の平方根**。

- 雑魚 ≈ 1.0 → 従来どおり（攻撃で 4%）
- ボス ≈ 2.0〜2.25 → 頭打ちの 2.5 倍（攻撃で 10%、ためた直後なら 20%）

攻撃力どうしの比は使っていない。ルカの攻撃力は武器で跳ね上がるので、それで
測ると序盤の雑魚が軒並み「格下」になり、**一番閃いてほしい時期に閃かなくなる**。
経験値は作り手が付けた強さの値そのもので、どの章でもボスは雑魚の 4〜6 倍と
比が安定しているため、こちらを物差しにしている。
